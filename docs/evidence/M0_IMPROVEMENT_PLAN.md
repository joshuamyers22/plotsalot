# M0 Improvement Plan

M0 closeout establishes a baseline, not final performance or approval of future
method families. Carry these actions forward:

1. Run future benchmark comparisons on the same host and investigate a median
   time or peak-allocation regression above 20% before accepting it.
2. Add scatter/correlation workloads under the M2 contract when those paths
   have real analysis and rendering boundaries.
3. Add held-out and sensitivity fixtures before promoting `gghistostats` from
   prototype to an approved compatibility tier.
